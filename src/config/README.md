### What is this `src/config/satis.json` about

It is a source configuration for the Tiki Satis/Composer mirror. For more details [Check here](https://dev.tiki.org/composer-tiki-org). 

It lives in the repository's `src/config/` directory because it is declarative configuration rather
than a developer script.
